GUIDELALA COURSE FINDER — GITHUB PAGES UPLOAD

IMPORTANT: Upload the CONTENTS of this folder, not the ZIP file itself.

1. In the GitHub repository, delete the old index.html and old assets folder.
2. Click Add file → Upload files.
3. Drag and upload:
   - index.html
   - style.css
   - app.js
   - courses.json
   - manifest.json
   - .nojekyll
   - assets folder
   - icons folder
4. Commit changes.
5. Wait 1–3 minutes.
6. Open:
   https://helpguidelala-aman.github.io/IGNOU-catalogue-guidelala/

QUICK CHECK
- The repository root must show index.html, style.css, app.js and courses.json.
- The assets and icons folders must be visible.
- Do not rename courses.json or app.js.
- A direct GitHub Pages URL is required; do not open index.html through GitHub's file preview.

FUTURE COURSE UPDATES
Only replace courses.json when the programme/course list changes.
